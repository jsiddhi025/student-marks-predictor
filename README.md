# Student Marks Predictor

A beginner machine learning project that predicts student marks based on study hours.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Git
- GitHub

## How It Works

1. Student data is stored in a CSV file.
2. The machine learning model learns from study hours and marks.
3. The user enters study hours.
4. The model predicts the expected marks.

## Project Structure

- `data/students.csv` - Dataset
- `train.py` - Trains the machine learning model
- `predict.py` - Predicts marks
- `requirements.txt` - Required Python libraries
